## Why This Handbook Exists

Fastlane is the undisputed standard for automating Android and iOS builds, code signing, and app store deployment. However, modern mobile engineers primarily build applications with **Flutter (Dart)**, **React Native (TypeScript)**, **Kotlin**, and **Swift**. 

Fastlane's official documentation leaves major operational gaps:
1. **Omitted Parameters & Options**: Hundreds of valid options exist in lower-level libraries (`supply`, `deliver`, `gym`, `pilot`) that are undocumented on the main site.
2. **The Ruby Syntax Barrier**: Mobile developers frequently struggle with Ruby idioms: Symbols vs Strings, closure blocks, hashes, and exception rescuing.
3. **Missing Production Architectures**: Real-world setups (multi-flavor branding, keystore pre-flights, zero-rebuild track promotions) require inspecting raw Ruby source code.
4. **Lane Context Obscurity**: Actions share data through `Actions.lane_context[SharedValues::...]`, but this flow is invisible in typical tutorials.
