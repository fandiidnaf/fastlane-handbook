> Select an Xcode to use by version specifier

## Details

Finds and selects a version of an installed Xcode that best matches the provided [`Gem::Version` requirement specifier](http://www.rubydoc.info/github/rubygems/rubygems/Gem/Version)
You can either manually provide a specific version using `version:` or you make use of the `.xcode-version` file.

## Parameters & Options

Total options available: **1**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `version` | `String` | `FL_XCODE_VERSION` | `-` | **Yes** | The version of Xcode to select specified as a Gem::Version requirement string (e.g. '~&gt; 7.1.0'). Defaults to the value specified in the .xcode-version file  |


## Examples

```ruby
xcversion(version: "8.1") # Selects Xcode 8.1.0
```

```ruby
xcversion(version: "~> 8.1.0") # Selects the latest installed version from the 8.1.x set
```

```ruby
xcversion # When missing, the version value defaults to the value specified in the .xcode-version file
```
