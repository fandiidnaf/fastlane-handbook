## Parameters & Options

Total options available: **4**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `project_name` | `String` | `FL_LCOV_PROJECT_NAME` | `-` | **Yes** | Name of the project |
| `scheme` | `String` | `FL_LCOV_SCHEME` | `-` | **Yes** | Scheme of the project |
| `arch` | `String` | `FL_LCOV_ARCH` | `i386` | **Yes** | The build arch where will search .gcda files |
| `output_dir` | `String` | `FL_LCOV_OUTPUT_DIR` | `coverage_reports` | No | The output directory that coverage data will be stored. If not passed will use coverage_reports as default value |


## Examples

```ruby
lcov(
            project_name: "ProjectName",
            scheme: "yourScheme",
            output_dir: "cov_reports" # This value is optional. Default is coverage_reports
          )
```
