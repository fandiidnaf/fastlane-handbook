> Downloads Xcode Bot assets like the `.xcarchive` and logs

## Details

This action downloads assets from your Xcode Server Bot (works with Xcode Server using Xcode 6 and 7. By default, this action downloads all assets, unzips them and deletes everything except for the `.xcarchive`.
If you'd like to keep all downloaded assets, pass `keep_all_assets: true`.
This action returns the path to the downloaded assets folder and puts into shared values the paths to the asset folder and to the `.xcarchive` inside it.

## Parameters & Options

Total options available: **8**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `host` | `String` | `FL_XCODE_SERVER_GET_ASSETS_HOST` | `-` | **Yes** | IP Address/Hostname of Xcode Server |
| `bot_name` | `String` | `FL_XCODE_SERVER_GET_ASSETS_BOT_NAME` | `-` | **Yes** | Name of the Bot to pull assets from |
| `integration_number` | `Integer` | `FL_XCODE_SERVER_GET_ASSETS_INTEGRATION_NUMBER` | `-` | No | Optionally you can override which integration's assets should be downloaded. If not provided, the latest integration is used |
| `username` | `String` | `FL_XCODE_SERVER_GET_ASSETS_USERNAME` | `-` | No | Username for your Xcode Server |
| `password` | `String` | `FL_XCODE_SERVER_GET_ASSETS_PASSWORD` | `-` | No | Password for your Xcode Server |
| `target_folder` | `String` | `FL_XCODE_SERVER_GET_ASSETS_TARGET_FOLDER` | `./xcs_assets` | No | Relative path to a folder into which to download assets |
| `keep_all_assets` | `Fastlane::Boolean` | `FL_XCODE_SERVER_GET_ASSETS_KEEP_ALL_ASSETS` | `false` | No | Whether to keep all assets or let the script delete everything except for the .xcarchive |
| `trust_self_signed_certs` | `Fastlane::Boolean` | `FL_XCODE_SERVER_GET_ASSETS_TRUST_SELF_SIGNED_CERTS` | `true` | No | Whether to trust self-signed certs on your Xcode Server |

## Lane Context Shared Values

This action writes the following values to `Actions.lane_context[SharedValues::...]`:

| Key | Description |
| :--- | :--- |
| `SharedValues::XCODE_SERVER_GET_ASSETS_PATH` | Absolute path to the downloaded assets folder |
| `SharedValues::XCODE_SERVER_GET_ASSETS_ARCHIVE_PATH` | Absolute path to the downloaded xcarchive file |

## Examples

```ruby
xcode_server_get_assets(
            host: "10.99.0.59", # Specify Xcode Server's Host or IP Address
            bot_name: "release-1.3.4" # Specify the particular Bot
          )
```
