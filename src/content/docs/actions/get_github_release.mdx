## Parameters & Options

Total options available: **5**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `url` | `String` | `FL_GET_GITHUB_RELEASE_URL` | `-` | **Yes** | The path to your repo, e.g. 'KrauseFx/fastlane' |
| `server_url` | `String` | `FL_GITHUB_RELEASE_SERVER_URL` | `https://api.github.com` | No | The server url. e.g. 'https://your.github.server/api/v3' (Default: 'https://api.github.com') |
| `version` | `String` | `FL_GET_GITHUB_RELEASE_VERSION` | `-` | **Yes** | The version tag of the release to check |
| `api_token` | `String` | `FL_GITHUB_RELEASE_API_TOKEN` | `-` | No | GitHub Personal Token (required for private repositories) |
| `api_bearer` | `String` | `FL_GITHUB_RELEASE_API_BEARER` | `-` | No | Use a Bearer authorization token. Usually generated by GitHub Apps, e.g. GitHub Actions GITHUB_TOKEN environment variable |

## Lane Context Shared Values

This action writes the following values to `Actions.lane_context[SharedValues::...]`:

| Key | Description |
| :--- | :--- |
| `SharedValues::GET_GITHUB_RELEASE_INFO` | Contains all the information about this release |

## Examples

```ruby
release = get_github_release(url: "fastlane/fastlane", version: "1.0.0")
puts release["name"]
```
