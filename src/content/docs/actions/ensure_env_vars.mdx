> Raises an exception if the specified env vars are not set

## Details

This action will check if some environment variables are set.

## Parameters & Options

Total options available: **1**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `env_vars` | `Array` | `-` | `-` | **Yes** | The environment variables names that should be checked |


## Examples

```ruby
ensure_env_vars(
  env_vars: ['GITHUB_USER_NAME', 'GITHUB_API_TOKEN']
)
```
