> Runs Swift Package Manager on your project


## Parameters & Options

Total options available: **16**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `command` | `String` | `FL_SPM_COMMAND` | `build` | **Yes** | The swift command (one of: build, test, clean, reset, update, resolve, generate-xcodeproj, init) |
| `enable_code_coverage` | `Fastlane::Boolean` | `FL_SPM_ENABLE_CODE_COVERAGE` | `-` | No | Enables code coverage for the generated Xcode project when using the 'generate-xcodeproj' and the 'test' command |
| `scratch_path` | `String` | `FL_SPM_SCRATCH_PATH` | `-` | No | Specify build/cache directory [default: ./.build] |
| `parallel` | `Fastlane::Boolean` | `FL_SPM_PARALLEL` | `false` | **Yes** | Enables running tests in parallel when using the 'test' command |
| `build_path` | `String` | `FL_SPM_BUILD_PATH` | `-` | No | **DEPRECATED!** `build_path` option is deprecated, use `scratch_path` instead - Specify build/cache directory [default: ./.build] |
| `package_path` | `String` | `FL_SPM_PACKAGE_PATH` | `-` | No | Change working directory before any other operation |
| `xcconfig` | `String` | `FL_SPM_XCCONFIG` | `-` | No | Use xcconfig file to override swift package generate-xcodeproj defaults |
| `configuration` | `String` | `FL_SPM_CONFIGURATION` | `-` | No | Build with configuration (debug\|release) [default: debug] |
| `disable_sandbox` | `Fastlane::Boolean` | `FL_SPM_DISABLE_SANDBOX` | `false` | No | Disable using the sandbox when executing subprocesses |
| `xcpretty_output` | `String` | `FL_SPM_XCPRETTY_OUTPUT` | `-` | No | Specifies the output type for xcpretty. eg. 'test', or 'simple' |
| `xcpretty_args` | `String` | `FL_SPM_XCPRETTY_ARGS` | `-` | No | Pass in xcpretty additional command line arguments (e.g. '--test --no-color' or '--tap --no-utf'), requires xcpretty_output to be specified also |
| `skip_update` | `Fastlane::Boolean` | `FL_SPM_SKIP_UPDATE` | `false` | **Yes** | Skip updating dependencies from their remote during a resolution |
| `verbose` | `Fastlane::Boolean` | `FL_SPM_VERBOSE` | `false` | **Yes** | Increase verbosity of informational output |
| `very_verbose` | `Fastlane::Boolean` | `FL_SPM_VERY_VERBOSE` | `false` | **Yes** | Increase verbosity to include debug output |
| `simulator` | `String` | `FL_SPM_SIMULATOR` | `-` | No | Specifies the simulator to pass for Swift Compiler (one of: iphonesimulator, macosx) |
| `simulator_arch` | `String` | `FL_SPM_SIMULATOR_ARCH` | `arm64` | **Yes** | Specifies the architecture of the simulator to pass for Swift Compiler (one of: x86_64, arm64). Requires the simulator option to be specified also, otherwise, it's ignored |


## Examples

```ruby
spm
```

```ruby
spm(
  command: "build",
  scratch_path: "./build",
  configuration: "release"
)
```

```ruby
spm(
  command: "generate-xcodeproj",
  xcconfig: "Package.xcconfig"
)
```

```ruby
spm(
  command: "test",
  parallel: true
)
```

```ruby
spm(
  simulator: "iphonesimulator"
)
```

```ruby
spm(
  simulator: "macosx",
  simulator_arch: "arm64"
)
```
