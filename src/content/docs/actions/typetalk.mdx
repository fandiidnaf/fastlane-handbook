## Parameters & Options

This action takes no parameters or options.


## Examples

```ruby
typetalk(
            message: "App successfully released!",
            note_path: "ChangeLog.md",
            topicId: 1,
            success: true,
            typetalk_token: "Your Typetalk Token"
          )
```
