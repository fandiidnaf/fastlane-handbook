**Supported Platforms:** `ios`, `mac`

> Set the build number from the current repository

## Details

This action will set the **build number** according to what the SCM HEAD reports.
Currently supported SCMs are svn (uses root revision), git-svn (uses svn revision) and git (uses short hash) and mercurial (uses short hash or revision number).
There is an option, `:use_hg_revision_number`, which allows to use mercurial revision number instead of hash.

## Parameters & Options

Total options available: **2**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `use_hg_revision_number` | `Fastlane::Boolean` | `USE_HG_REVISION_NUMBER` | `false` | No | Use hg revision number instead of hash (ignored for non-hg repos) |
| `xcodeproj` | `String` | `XCODEPROJ_PATH` | `-` | No | explicitly specify which xcodeproj to use |


## Examples

```ruby
set_build_number_repository
```

```ruby
set_build_number_repository(
  xcodeproj: "./path/to/MyApp.xcodeproj"
)
```
