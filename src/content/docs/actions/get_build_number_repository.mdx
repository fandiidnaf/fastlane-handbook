> Get the build number from the current repository

## Details

This action will get the **build number** according to what the SCM HEAD reports.
Currently supported SCMs are svn (uses root revision), git-svn (uses svn revision), git (uses short hash) and mercurial (uses short hash or revision number).
There is an option, `:use_hg_revision_number`, which allows to use mercurial revision number instead of hash.

## Parameters & Options

Total options available: **1**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `use_hg_revision_number` | `Fastlane::Boolean` | `USE_HG_REVISION_NUMBER` | `false` | No | Use hg revision number instead of hash (ignored for non-hg repos) |

## Lane Context Shared Values

This action writes the following values to `Actions.lane_context[SharedValues::...]`:

| Key | Description |
| :--- | :--- |
| `SharedValues::BUILD_NUMBER_REPOSITORY` | The build number from the current repository |
