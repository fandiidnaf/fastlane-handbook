> Raises an exception if not on a specific git branch

## Details

This action will check if your git repo is checked out to a specific branch.
You may only want to make releases from a specific branch, so `ensure_git_branch` will stop a lane if it was accidentally executed on an incorrect branch.

## Parameters & Options

Total options available: **1**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `branch` | `String` | `FL_ENSURE_GIT_BRANCH_NAME` | `master` | **Yes** | The branch that should be checked for. String that can be either the full name of the branch or a regex e.g. `^feature/.*$` to match |


## Examples

```ruby
ensure_git_branch # defaults to `master` branch
```

```ruby
ensure_git_branch(
  branch: 'develop'
)
```
