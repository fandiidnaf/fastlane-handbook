**Supported Platforms:** `ios`, `mac`

> Deletes the Xcode Derived Data

## Details

Deletes the Derived Data from path set on Xcode or a supplied path

## Parameters & Options

Total options available: **1**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `derived_data_path` | `String` | `DERIVED_DATA_PATH` | `~/Library/Developer/Xcode/DerivedData` | **Yes** | Custom path for derivedData |


## Examples

```ruby
clear_derived_data
```

```ruby
clear_derived_data(derived_data_path: "/custom/")
```
