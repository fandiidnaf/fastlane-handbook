**Supported Platforms:** `ios`

> This action changes the keychain access groups in the entitlements file

## Details

Updates the Keychain Group Access Groups in the given Entitlements file, so you can have keychain access groups for the app store build and keychain access groups for an enterprise build.

## Parameters & Options

Total options available: **2**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `entitlements_file` | `String` | `FL_UPDATE_KEYCHAIN_ACCESS_GROUPS_ENTITLEMENTS_FILE_PATH` | `-` | **Yes** | The path to the entitlement file which contains the keychain access groups |
| `identifiers` | `Array` | `FL_UPDATE_KEYCHAIN_ACCESS_GROUPS_IDENTIFIERS` | `-` | **Yes** | An Array of unique identifiers for the keychain access groups. Eg. ['your.keychain.access.groups.identifiers'] |

## Lane Context Shared Values

This action writes the following values to `Actions.lane_context[SharedValues::...]`:

| Key | Description |
| :--- | :--- |
| `SharedValues::KEYCHAIN_ACCESS_GROUPS` | The new Keychain Access Groups |

## Examples

```ruby
update_keychain_access_groups(
  entitlements_file: "/path/to/entitlements_file.entitlements",
  identifiers: ["your.keychain.access.groups.identifiers"]
)
```
