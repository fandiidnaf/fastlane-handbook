> Returns the current build_number of either live or edit version

## Details

Returns the current build number of either the live or testflight version - it is useful for getting the build_number of the current or ready-for-sale app version, and it also works on non-live testflight version.
If you need to handle more build-trains please see `latest_testflight_build_number`.

## Parameters & Options

Total options available: **10**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `api_key_path` | `String` | `-` | `-` | No | Path to your App Store Connect API Key JSON file (https://docs.fastlane.tools/app-store-connect-api/#using-fastlane-api-key-json-file) |

| `username` | `String` | `ITUNESCONNECT_USER` | `-` | No | Your Apple ID Username |
| `team_id` | `String` | `APPSTORE_BUILD_NUMBER_LIVE_TEAM_ID` | `-` | No | The ID of your App Store Connect team if you're in multiple teams |
| `live` | `Fastlane::Boolean` | `APPSTORE_BUILD_NUMBER_LIVE` | `true` | No | Query the live version (ready-for-sale) |
| `version` | `String` | `LATEST_VERSION` | `-` | No | The version number whose latest build number we want |
| `platform` | `String` | `APPSTORE_PLATFORM` | `ios` | No | The platform to use (optional) |
| `team_name` | `String` | `LATEST_TESTFLIGHT_BUILD_NUMBER_TEAM_NAME` | `-` | No | The name of your App Store Connect team if you're in multiple teams |
