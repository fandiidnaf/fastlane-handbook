> Compress a file or folder to a zip


## Parameters & Options

Total options available: **7**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `path` | `String` | `FL_ZIP_PATH` | `-` | **Yes** | Path to the directory or file to be zipped |
| `output_path` | `String` | `FL_ZIP_OUTPUT_NAME` | `-` | No | The name of the resulting zip file |
| `verbose` | `Fastlane::Boolean` | `FL_ZIP_VERBOSE` | `true` | No | Enable verbose output of zipped file |
| `password` | `String` | `FL_ZIP_PASSWORD` | `-` | No | Encrypt the contents of the zip archive using a password |
| `symlinks` | `Fastlane::Boolean` | `FL_ZIP_SYMLINKS` | `false` | No | Store symbolic links as such in the zip archive |
| `include` | `Array` | `FL_ZIP_INCLUDE` | `[]` | No | Array of paths or patterns to include |
| `exclude` | `Array` | `FL_ZIP_EXCLUDE` | `[]` | No | Array of paths or patterns to exclude |


## Examples

```ruby
zip
```

```ruby
zip(
  path: "MyApp.app",
  output_path: "Latest.app.zip"
)
```

```ruby
zip(
  path: "MyApp.app",
  output_path: "Latest.app.zip",
  verbose: false
)
```

```ruby
zip(
  path: "MyApp.app",
  output_path: "Latest.app.zip",
  verbose: false,
  symlinks: true
)
```

```ruby
zip(
  path: "./",
  output_path: "Source Code.zip",
  exclude: [".git/*"]
)
```

```ruby
zip(
  path: "./",
  output_path: "Swift Code.zip",
  include: ["**/*.swift"],
  exclude: ["Package.swift", "vendor/*", "Pods/*"]
)
```
