**Supported Platforms:** `ios`, `mac`

> Returns a value from Info.plist inside a .ipa file

## Details

This is useful for introspecting Info.plist files for `.ipa` files that have already been built.

## Parameters & Options

Total options available: **2**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `key` | `String` | `FL_GET_IPA_INFO_PLIST_VALUE_KEY` | `-` | **Yes** | Name of parameter |
| `ipa` | `String` | `FL_GET_IPA_INFO_PLIST_VALUE_IPA` | `-` | **Yes** | Path to IPA |

## Lane Context Shared Values

This action writes the following values to `Actions.lane_context[SharedValues::...]`:

| Key | Description |
| :--- | :--- |
| `SharedValues::GET_IPA_INFO_PLIST_VALUE_CUSTOM_VALUE` | The value of the last plist file that was parsed |

## Examples

```ruby
get_ipa_info_plist_value(ipa: "path.ipa", key: "KEY_YOU_READ")
```
