> Runs test coverage reports for your Xcode project

## Details

Generate summarized code coverage reports using [gcovr](http://gcovr.com/)

## Parameters & Options

This action takes no parameters or options.


## Examples

```ruby
gcovr(
  html: true,
  html_details: true,
  output: "./code-coverage/report.html"
)
```
