**Supported Platforms:** `ios`, `mac`

> Pod lib lint

## Details

Test the syntax of your Podfile by linting the pod against the files of its directory

## Parameters & Options

Total options available: **20**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `use_bundle_exec` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_USE_BUNDLE` | `true` | **Yes** | Use bundle exec when there is a Gemfile presented |
| `podspec` | `String` | `FL_POD_LIB_LINT_PODSPEC` | `-` | No | Path of spec to lint |
| `verbose` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_VERBOSE` | `-` | No | Allow output detail in console |
| `allow_warnings` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_ALLOW_WARNINGS` | `-` | No | Allow warnings during pod lint |
| `sources` | `Array` | `FL_POD_LIB_LINT_SOURCES` | `-` | No | The sources of repos you want the pod spec to lint with, separated by commas |
| `subspec` | `String` | `FL_POD_LIB_LINT_SUBSPEC` | `-` | No | A specific subspec to lint instead of the entire spec |
| `include_podspecs` | `String` | `FL_POD_LIB_LINT_INCLUDE_PODSPECS` | `-` | No | A Glob of additional ancillary podspecs which are used for linting via :path (available since cocoapods &gt;= 1.7) |
| `external_podspecs` | `String` | `FL_POD_LIB_LINT_EXTERNAL_PODSPECS` | `-` | No | A Glob of additional ancillary podspecs which are used for linting via :podspec. If there are --include-podspecs, then these are removed from them (available since cocoapods &gt;= 1.7) |
| `swift_version` | `String` | `FL_POD_LIB_LINT_SWIFT_VERSION` | `-` | No | The SWIFT_VERSION that should be used to lint the spec. This takes precedence over a .swift-version file |
| `use_libraries` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_USE_LIBRARIES` | `false` | **Yes** | Lint uses static libraries to install the spec |
| `use_modular_headers` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_USE_MODULAR_HEADERS` | `false` | **Yes** | Lint using modular libraries (available since cocoapods &gt;= 1.6) |
| `fail_fast` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_FAIL_FAST` | `false` | **Yes** | Lint stops on the first failing platform or subspec |
| `private` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_PRIVATE` | `false` | **Yes** | Lint skips checks that apply only to public specs |
| `quick` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_QUICK` | `false` | **Yes** | Lint skips checks that would require to download and build the spec |
| `no_clean` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_NO_CLEAN` | `false` | **Yes** | Lint leaves the build directory intact for inspection |
| `no_subspecs` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_NO_SUBSPECS` | `false` | **Yes** | Lint skips validation of subspecs |
| `platforms` | `String` | `FL_POD_LIB_LINT_PLATFORMS` | `-` | No | Lint against specific platforms (defaults to all platforms supported by the podspec). Multiple platforms must be comma-delimited (available since cocoapods &gt;= 1.6) |
| `skip_import_validation` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_SKIP_IMPORT_VALIDATION` | `false` | **Yes** | Lint skips validating that the pod can be imported (available since cocoapods &gt;= 1.3) |
| `skip_tests` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_SKIP_TESTS` | `false` | **Yes** | Lint skips building and running tests during validation (available since cocoapods &gt;= 1.3) |
| `analyze` | `Fastlane::Boolean` | `FL_POD_LIB_LINT_ANALYZE` | `false` | **Yes** | Validate with the Xcode Static Analysis tool (available since cocoapods &gt;= 1.6.1) |


## Examples

```ruby
pod_lib_lint
```

```ruby
# Allow output detail in console
pod_lib_lint(verbose: true)
```

```ruby
# Allow warnings during pod lint
pod_lib_lint(allow_warnings: true)
```

```ruby
# If the podspec has a dependency on another private pod, then you will have to supply the sources
pod_lib_lint(sources: ["https://github.com/username/Specs", "https://github.com/CocoaPods/Specs"])
```
