## Parameters & Options

Total options available: **2**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `text` | `Array` | `-` | `-` | **Yes** | Text to be spoken out loud (as string or array of strings) |
| `mute` | `Fastlane::Boolean` | `SAY_MUTE` | `false` | **Yes** | If say should be muted with text printed out |


## Examples

