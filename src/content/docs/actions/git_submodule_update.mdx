**Supported Platforms:** `ios`, `android`, `mac`

> Executes a git submodule update command


## Parameters & Options

Total options available: **2**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `recursive` | `Fastlane::Boolean` | `-` | `false` | **Yes** | Should the submodules be updated recursively? |
| `init` | `Fastlane::Boolean` | `-` | `false` | **Yes** | Should the submodules be initiated before update? |


## Examples

```ruby
git_submodule_update
```

```ruby
git_submodule_update(recursive: true)
```

```ruby
git_submodule_update(init: true)
```

```ruby
git_submodule_update(recursive: true, init: true)
```
