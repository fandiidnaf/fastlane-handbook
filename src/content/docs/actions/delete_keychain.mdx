**Supported Platforms:** `ios`, `android`, `mac`

> Delete keychains and remove them from the search list

## Details

Keychains can be deleted after being created with `create_keychain`

## Parameters & Options

Total options available: **2**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `name` | `String` | `KEYCHAIN_NAME` | `-` | No | Keychain name |
| `keychain_path` | `String` | `KEYCHAIN_PATH` | `-` | No | Keychain path |


## Examples

```ruby
delete_keychain(name: "KeychainName")
```

```ruby
delete_keychain(keychain_path: "/keychains/project.keychain")
```
