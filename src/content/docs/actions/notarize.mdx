## Parameters & Options

Total options available: **10**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `package` | `String` | `FL_NOTARIZE_PACKAGE` | `-` | **Yes** | Path to package to notarize, e.g. .app bundle or disk image |
| `skip_stapling` | `Fastlane::Boolean` | `FL_NOTARIZE_SKIP_STAPLING` | `false` | No | Do not staple the notarization ticket to the artifact; useful for single file executables and ZIP archives |
| `username` | `String` | `FL_NOTARIZE_USERNAME` | `-` | No | Apple ID username |
| `asc_provider` | `String` | `FL_NOTARIZE_ASC_PROVIDER` | `-` | No | Provider short name for accounts associated with multiple providers |
| `print_log` | `Fastlane::Boolean` | `FL_NOTARIZE_PRINT_LOG` | `false` | No | Whether to print notarization log file, listing issues on failure and warnings on success |
| `verbose` | `Fastlane::Boolean` | `FL_NOTARIZE_VERBOSE` | `false` | No | Whether to log requests |
| `api_key_path` | `String` | `-` | `-` | No | Path to your App Store Connect API Key JSON file (https://docs.fastlane.tools/app-store-connect-api/#using-fastlane-api-key-json-file) |
| `api_key` | `Hash` | `-` | `-` | No | Your App Store Connect API Key information (https://docs.fastlane.tools/app-store-connect-api/#using-fastlane-api-key-hash-option) |
| `keychain_path` | `String` | `FL_NOTARIZE_KEYCHAIN_PATH` | `-` | No | The path to a keychain file to use for reading the keychain item. If not specified, the default user keychain is used |
| `keychain_profile` | `String` | `FL_NOTARIZE_KEYCHAIN_PROFILE` | `-` | No | Authenticate with credentials stored in the Keychain. Use the profile name you provided in the "xcrun notarytool store-credentials" command. Unlike :username, no app-specific password is passed on the command line, so prefer it when you do not use an API key |


## Examples

```ruby
notarize(
  package: "MyApp.app",
  api_key_path: "fastlane/AuthKey.json"
)
```

```ruby
# If you want to notarize locally but don't have access to the API key,
# you can notarize using stored credentials:
#
# 1. Run `xcrun notarytool store-credentials --team-id "TEAM_ID" --apple-id "APPLE_ID"`
# 2. There will be prompts for the profile name and the app-specific password (so the password never appears on the command line).
# 3. The specified profile name can be used at any time without the need to specify team ID, username and password:
#    `xcrun notarytool submit --keychain-profile KEYCHAIN_PROFILE_NAME`
notarize(
  package: "MyApp.app",
  keychain_profile: "AC_PASSWORD",
  keychain_path: "~/Library/Keychains/notarization.keychain-db"
)
```
