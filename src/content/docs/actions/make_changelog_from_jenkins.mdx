**Supported Platforms:** `ios`, `android`, `mac`

> Generate a changelog using the Changes section from the current Jenkins build

## Details

This is useful when deploying automated builds. The changelog from Jenkins lists all the commit messages since the last build.

## Parameters & Options

Total options available: **2**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `fallback_changelog` | `String` | `-` | `-` | No | Fallback changelog if there is not one on Jenkins, or it couldn't be read |
| `include_commit_body` | `Fastlane::Boolean` | `-` | `true` | No | Include the commit body along with the summary |

## Lane Context Shared Values

This action writes the following values to `Actions.lane_context[SharedValues::...]`:

| Key | Description |
| :--- | :--- |
| `SharedValues::FL_CHANGELOG` | The changelog generated by Jenkins |

## Examples

```ruby
make_changelog_from_jenkins(
  # Optional, lets you set a changelog in the case is not generated on Jenkins or if ran outside of Jenkins
  fallback_changelog: "Bug fixes and performance enhancements"
)
```
