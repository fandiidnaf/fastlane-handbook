> Copies a given string into the clipboard. Works only on macOS


## Parameters & Options

Total options available: **1**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `value` | `String` | `FL_CLIPBOARD_VALUE` | `-` | **Yes** | The string that should be copied into the clipboard |


## Examples

```ruby
clipboard(value: "https://docs.fastlane.tools/")
```

```ruby
clipboard(value: lane_context[SharedValues::HOCKEY_DOWNLOAD_LINK] || "")
```
