> Find, print, and copy Spaceship logs


## Parameters & Options

Total options available: **5**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `latest` | `Fastlane::Boolean` | `-` | `true` | **Yes** | Finds only the latest Spaceshop log file if set to true, otherwise returns all |
| `print_contents` | `Fastlane::Boolean` | `-` | `false` | **Yes** | Prints the contents of the found Spaceship log file(s) |
| `print_paths` | `Fastlane::Boolean` | `-` | `false` | **Yes** | Prints the paths of the found Spaceship log file(s) |
| `copy_to_path` | `String` | `-` | `-` | No | Copies the found Spaceship log file(s) to a directory |
| `copy_to_clipboard` | `Fastlane::Boolean` | `-` | `false` | **Yes** | Copies the contents of the found Spaceship log file(s) to the clipboard |


## Examples

```ruby
spaceship_logs
```

```ruby
spaceship_logs(
  copy_to_path: "/tmp/artifacts"
)
```

```ruby
spaceship_logs(
  copy_to_clipboard: true
)
```

```ruby
spaceship_logs(
  print_contents: true,
  print_paths: true
)
```

```ruby
spaceship_logs(
  latest: false,
  print_contents: true,
  print_paths: true
)
```
