## Parameters & Options

Total options available: **16**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `mailgun_sandbox_domain` | `String` | `MAILGUN_SANDBOX_POSTMASTER` | `-` | No | Mailgun sandbox domain postmaster for your mail. Please use postmaster instead |
| `mailgun_sandbox_postmaster` | `String` | `MAILGUN_SANDBOX_POSTMASTER` | `-` | No | Mailgun sandbox domain postmaster for your mail. Please use postmaster instead |
| `mailgun_apikey` | `String` | `MAILGUN_APIKEY` | `-` | No | Mailgun apikey for your mail. Please use postmaster instead |
| `postmaster` | `String` | `MAILGUN_SANDBOX_POSTMASTER` | `-` | **Yes** | Mailgun sandbox domain postmaster for your mail |
| `apikey` | `String` | `MAILGUN_APIKEY` | `-` | **Yes** | Mailgun apikey for your mail |
| `to` | `String` | `MAILGUN_TO` | `-` | **Yes** | Destination of your mail |
| `from` | `String` | `MAILGUN_FROM` | `Mailgun Sandbox` | No | Mailgun sender name |
| `message` | `String` | `MAILGUN_MESSAGE` | `-` | **Yes** | Message of your mail |
| `subject` | `String` | `MAILGUN_SUBJECT` | `fastlane build` | No | Subject of your mail |
| `success` | `Fastlane::Boolean` | `MAILGUN_SUCCESS` | `true` | No | Was this build successful? (true/false) |
| `app_link` | `String` | `MAILGUN_APP_LINK` | `-` | **Yes** | App Release link |
| `ci_build_link` | `String` | `MAILGUN_CI_BUILD_LINK` | `-` | No | CI Build Link |
| `template_path` | `String` | `MAILGUN_TEMPLATE_PATH` | `-` | No | Mail HTML template |
| `reply_to` | `String` | `MAILGUN_REPLY_TO` | `-` | No | Mail Reply to |
| `attachment` | `Array` | `MAILGUN_ATTACHMENT` | `-` | No | Mail Attachment filenames, either an array or just one string |
| `custom_placeholders` | `Hash` | `MAILGUN_CUSTOM_PLACEHOLDERS` | `&#123;&#125;` | **Yes** | Placeholders for template given as a hash |


## Examples

```ruby
mailgun(
  to: "fastlane@krausefx.com",
  success: true,
  message: "This is the mail's content"
)
```

```ruby
mailgun(
  postmaster: "MY_POSTMASTER",
  apikey: "MY_API_KEY",
  to: "DESTINATION_EMAIL",
  from: "EMAIL_FROM_NAME",
  reply_to: "EMAIL_REPLY_TO",
  success: true,
  message: "Mail Body",
  app_link: "http://www.myapplink.com",
  ci_build_link: "http://www.mycibuildlink.com",
  template_path: "HTML_TEMPLATE_PATH",
  custom_placeholders: {
    :var1 => 123,
    :var2 => "string"
  },
  attachment: "dirname/filename.ext"
)
```
