**Supported Platforms:** `ios`, `android`, `mac`

> Setup the keychain and match to work with CircleCI

## Details

- Creates a new temporary keychain for use with match|
- Switches match to `readonly` mode to not create new profiles/cert on CI|
- Sets up log and test result paths to be easily collectible|
>|
This action helps with CircleCI integration. Add this to the top of your Fastfile if you use CircleCI.

## Parameters & Options

Total options available: **1**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `force` | `Fastlane::Boolean` | `FL_SETUP_CIRCLECI_FORCE` | `false` | **Yes** | Force setup, even if not executed by CircleCI |


## Examples

```ruby
setup_circle_ci
```
