## Parameters & Options

Total options available: **5**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `name` | `String` | `FL_CLEAN_COCOAPODS_CACHE_DEVELOPMENT` | `-` | No | Pod name to be removed from cache |
| `no_ansi` | `Fastlane::Boolean` | `FL_CLEAN_COCOAPODS_CACHE_NO_ANSI` | `false` | **Yes** | Show output without ANSI codes |
| `verbose` | `Fastlane::Boolean` | `FL_CLEAN_COCOAPODS_CACHE_VERBOSE` | `false` | **Yes** | Show more debugging information |
| `silent` | `Fastlane::Boolean` | `FL_CLEAN_COCOAPODS_CACHE_SILENT` | `false` | **Yes** | Show nothing |
| `allow_root` | `Fastlane::Boolean` | `FL_CLEAN_COCOAPODS_CACHE_ALLOW_ROOT` | `false` | **Yes** | Allows CocoaPods to run as root |
