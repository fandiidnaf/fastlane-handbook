## Parameters & Options

This action takes no parameters or options.

## Lane Context Shared Values

This action writes the following values to `Actions.lane_context[SharedValues::...]`:

| Key | Description |
| :--- | :--- |
| `SharedValues::SNAPSHOT_SCREENSHOTS_PATH` | The path to the screenshots |
