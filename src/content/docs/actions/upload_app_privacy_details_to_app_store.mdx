> Upload App Privacy Details for an app in App Store Connect

## Details

Upload App Privacy Details for an app in App Store Connect. For more detail information, view https://docs.fastlane.tools/uploading-app-privacy-details

## Parameters & Options

Total options available: **9**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `username` | `String` | `FASTLANE_USER` | `-` | **Yes** | Your Apple ID Username for App Store Connect |
| `app_identifier` | `String` | `UPLOAD_APP_PRIVACY_DETAILS_TO_APP_STORE_APP_IDENTIFIER` | `-` | **Yes** | The bundle identifier of your app |
| `team_id` | `String` | `FASTLANE_ITC_TEAM_ID` | `-` | No | The ID of your App Store Connect team if you're in multiple teams |
| `team_name` | `String` | `FASTLANE_ITC_TEAM_NAME` | `-` | No | The name of your App Store Connect team if you're in multiple teams |
| `json_path` | `String` | `UPLOAD_APP_PRIVACY_DETAILS_TO_APP_STORE_JSON_PATH` | `-` | No | Path to the app usage data JSON |
| `output_json_path` | `String` | `UPLOAD_APP_PRIVACY_DETAILS_TO_APP_STORE_OUTPUT_JSON_PATH` | `./app_privacy_details.json` | **Yes** | Path to the app usage data JSON file generated by interactive questions |
| `skip_json_file_saving` | `Fastlane::Boolean` | `UPLOAD_APP_PRIVACY_DETAILS_TO_APP_STORE_OUTPUT_SKIP_JSON_FILE_SAVING` | `false` | **Yes** | Whether to skip the saving of the JSON file |
| `skip_upload` | `Fastlane::Boolean` | `UPLOAD_APP_PRIVACY_DETAILS_TO_APP_STORE_OUTPUT_SKIP_UPLOAD` | `false` | **Yes** | Whether to skip the upload and only create the JSON file with interactive questions |
| `skip_publish` | `Fastlane::Boolean` | `UPLOAD_APP_PRIVACY_DETAILS_TO_APP_STORE_OUTPUT_SKIP_PUBLISH` | `false` | **Yes** | Whether to skip the publishing |


## Examples

```ruby
upload_app_privacy_details_to_app_store(
            username: "your@email.com",
            team_name: "Your Team",
            app_identifier: "com.your.bundle"
          )
```

          )
