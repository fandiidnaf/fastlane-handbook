## Parameters & Options

Total options available: **14**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `all_modules` | `Fastlane::Boolean` | `FL_SOURCEDOCS_OUTPUT_ALL_MODULES` | `-` | No | Generate documentation for all modules in a Swift package |
| `spm_module` | `String` | `FL_SOURCEDOCS_SPM_MODULE` | `-` | No | Generate documentation for Swift Package Manager module |
| `module_name` | `String` | `FL_SOURCEDOCS_MODULE_NAME` | `-` | No | Generate documentation for a Swift module |
| `link_beginning` | `String` | `FL_SOURCEDOCS_LINK_BEGINNING` | `-` | No | The text to begin links with |
| `link_ending` | `String` | `FL_SOURCEDOCS_LINK_ENDING` | `-` | No | The text to end links with (default: .md) |
| `output_folder` | `String` | `FL_SOURCEDOCS_OUTPUT_FOLDER` | `-` | **Yes** | Output directory to clean (default: Documentation/Reference) |
| `min_acl` | `String` | `FL_SOURCEDOCS_MIN_ACL` | `-` | No | Access level to include in documentation [private, fileprivate, internal, public, open] (default: public) |
| `module_name_path` | `Fastlane::Boolean` | `FL_SOURCEDOCS_MODULE_NAME_PATH` | `-` | No | Include the module name as part of the output folder path |
| `clean` | `Fastlane::Boolean` | `FL_SOURCEDOCS_CLEAN` | `-` | No | Delete output folder before generating documentation |
| `collapsible` | `Fastlane::Boolean` | `FL_SOURCEDOCS_COLLAPSIBLE` | `-` | No | Put methods, properties and enum cases inside collapsible blocks |
| `table_of_contents` | `Fastlane::Boolean` | `FL_SOURCEDOCS_TABLE_OF_CONTENT` | `-` | No | Generate a table of contents with properties and methods for each type |
| `reproducible` | `Fastlane::Boolean` | `FL_SOURCEDOCS_REPRODUCIBLE` | `-` | No | Generate documentation that is reproducible: only depends on the sources |
| `scheme` | `String` | `FL_SOURCEDOCS_SCHEME` | `-` | No | Create documentation for specific scheme |
| `sdk_platform` | `String` | `FL_SOURCEDOCS_SDK_PlATFORM` | `-` | No | Create documentation for specific sdk platform |


## Examples

```ruby
sourcedocs(output_folder: 'docs')
```

```ruby
sourcedocs(output_folder: 'docs', clean: true, reproducible: true, scheme: 'MyApp')
```
