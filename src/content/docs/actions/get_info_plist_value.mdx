**Supported Platforms:** `ios`, `mac`

> Returns value from Info.plist of your project as native Ruby data structures

## Details

Get a value from a plist file, which can be used to fetch the app identifier and more information about your app

## Parameters & Options

Total options available: **2**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `key` | `String` | `FL_GET_INFO_PLIST_PARAM_NAME` | `-` | **Yes** | Name of parameter |
| `path` | `String` | `FL_GET_INFO_PLIST_PATH` | `-` | **Yes** | Path to plist file you want to read |

## Lane Context Shared Values

This action writes the following values to `Actions.lane_context[SharedValues::...]`:

| Key | Description |
| :--- | :--- |
| `SharedValues::GET_INFO_PLIST_VALUE_CUSTOM_VALUE` | The value of the last plist file that was parsed |

## Examples

```ruby
identifier = get_info_plist_value(path: "./Info.plist", key: "CFBundleIdentifier")
```
