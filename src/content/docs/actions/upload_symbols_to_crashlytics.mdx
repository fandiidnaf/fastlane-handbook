**Supported Platforms:** `ios`

> Upload dSYM symbolication files to Crashlytics

## Details

This action allows you to upload symbolication files to Crashlytics. It's extra useful if you use it to download the latest dSYM files from Apple when you use Bitcode. This action will not fail the build if one of the uploads failed by default.
The reason for that is that sometimes some of dSYM files are invalid, and we don't want them to fail the complete build. However, fail_on_build parameter can be used to prevent this behavior.

## Parameters & Options

Total options available: **10**

| Key | Type | Env Variable | Default | Required | Description |
| :--- | :--- | :--- | :--- | :---: | :--- |
| `dsym_path` | `String` | `FL_UPLOAD_SYMBOLS_TO_CRASHLYTICS_DSYM_PATH` | `-` | No | Path to the DSYM file or zip to upload |
| `dsym_paths` | `Array` | `FL_UPLOAD_SYMBOLS_TO_CRASHLYTICS_DSYM_PATHS` | `-` | No | Paths to the DSYM files or zips to upload |
| `api_token` | `String` | `CRASHLYTICS_API_TOKEN` | `-` | No | Crashlytics API Key |
| `gsp_path` | `String` | `GOOGLE_SERVICES_INFO_PLIST_PATH` | `-` | No | Path to GoogleService-Info.plist |
| `app_id` | `String` | `CRASHLYTICS_APP_ID` | `-` | No | Firebase Crashlytics APP ID |
| `binary_path` | `String` | `FL_UPLOAD_SYMBOLS_TO_CRASHLYTICS_BINARY_PATH` | `-` | No | The path to the upload-symbols file of the Fabric app |
| `platform` | `String` | `FL_UPLOAD_SYMBOLS_TO_CRASHLYTICS_PLATFORM` | `ios` | **Yes** | The platform of the app (ios, appletvos, mac) |
| `dsym_worker_threads` | `Integer` | `FL_UPLOAD_SYMBOLS_TO_CRASHLYTICS_DSYM_WORKER_THREADS` | `1` | No | The number of threads to use for simultaneous dSYM upload |
| `fail_on_error` | `Fastlane::Boolean` | `FL_UPLOAD_SYMBOLS_TO_CRASHLYTICS_FAIL_ON_ERROR` | `false` | **Yes** | Should the action fail when an upload fails? |
| `debug` | `Fastlane::Boolean` | `FL_UPLOAD_SYMBOLS_TO_CRASHLYTICS_DEBUG` | `false` | **Yes** | Enable debug mode for upload-symbols |


## Examples

```ruby
upload_symbols_to_crashlytics(dsym_path: "./App.dSYM.zip")
```
