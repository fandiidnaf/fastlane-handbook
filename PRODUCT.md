# PRODUCT.md - Fastlane Handbook

## Vision
Fastlane Handbook is an independent, community-driven technical documentation website and reference manual for Fastlane. It bridges the gap between Fastlane's Ruby-centric implementation and modern mobile app engineers building apps with Flutter, React Native, Kotlin, and Swift.

## Target Audience
- Mobile software engineers and tech leads who manage CI/CD deployment pipelines.
- Developers migrating native or hybrid apps to automated app store deployment who do not have prior Ruby background.
- Engineers managing enterprise mobile requirements: multi-flavor branding, automated versioning, zero-rebuild track promotion, and secure credential handling.

## Non-Goals
- We are not a replacement for the Fastlane CLI or its maintainers.
- We do not host proprietary closed-source plugins.
- We do not write generic introductory blog posts; every page must contain reproducible code, parameter types, and concrete failure modes.
